Convention (2026-10-23): every AGENTS.md bullet states an action the reader takes or a checkable fact. A sentence about a document's role ('X is a guard that only routes edits', 'the protocol lives in Y') is not content: it is file biography, it goes stale the moment contents move, and it leaves the reader unable to act. Replacements name the rule first and the detailed file second ('Route every memory read and write through the gateway tools; never read/ls .serena/memories directly. The protocol is <path> — apply it, never restate it.'). Root cause is process, not style: content moves between files and the author records the move instead of the rule; AGENTS.md is a map, so describing a file feels like content; pointers replace rules during copy-append edits; and verify-agents only checked structure, never wording. Fix: gate #10 in the verify-agents recipe scans AGENTS.md for role/provenance phrasing (is a guard|pointer|router|shim|wrapper|single source|thin; this document|file|doc; lives in; file...provenance) and fails with file:line, the phrase, and what to write instead. Also: any 'N skills' style count is checked across every occurrence, because a first-match-only check lets the other copies drift. Do not add a second writing rule — .opencode/instructions/writing-style.instructions.md already forbids document biography; enforce it.
