Decision (2026-10-22, updated after rename): .opencode/agents/rug.md §Patterns has seven patterns, each with three-part metadata (summary, **When to use**, **Combine with**) and a body that is statement-level for the single execution envelope. The pattern formerly called execute-summarize-in-fork is now EXECUTE FIRST, SUMMARIZE LATER: the first call only executes and reports status/paths/decisions rather than prose; a fork of that child then writes the summary, extraction, or formatted answer from its live context, so execution and summarization never compete. A fork may also answer a closed yes/no probe; it never renders a verdict on its own artifact. Every reference, including this memory, uses the new name.
