# Memory System Domain

This domain documents the Serena memory system conventions — how memories are organized, named, cross-referenced, and managed within the `.serena/memories/` directory.

## Scope
- Serena memory tool reference (write, read, list, edit, rename, delete)
- Naming conventions and hierarchical organization
- Cross-referencing with `mem:` links
- Overview memory pattern (table of contents per topic group)
- Write patterns (single writes, batch hierarchies, append, defensive patterns)
- Manage patterns (edit literal/regex, rename with reference updates, delete with guards)
- Topic organization structure (overview + children pattern)
