# Skill Principles: Active-Voice Directives

Skill principles must be ACTIVE-VOICE DIRECTIVES ("Verify every write"), not noun-phrase labels ("Cache discipline" is a topic, not an instruction). Define load-bearing jargon once in a Vocabulary line in the pointer's reference (HIT/MISS, `mem:`, phase labels) — define, don't delete terms recipes and evals use. Check every always-loaded sentence against .github/instructions/writing-style.instructions.md: kicker-first, one idea per sentence, no nominalizations. Watch for undecodable artifacts: "step 0", "(general)", "STORE phase".
