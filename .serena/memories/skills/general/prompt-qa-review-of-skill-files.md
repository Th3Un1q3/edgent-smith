# Prompt-QA Review of Skill Files

Applying the prompt-QA methodology (.opencode/commands/prompt-qa.md) to skill files is a high-yield review pass. Its 6 categories — contradictions, ambiguity, persona consistency, cognitive load, semantic coverage, superstitious instructions — plus cross-file consistency checks caught, in one context-gathering pass: stale cross-file budget math, a misquoted authority, an unqualified rule with an undocumented carve-out, an impossible ordering instruction, an actor-shift in voice, a missing failure-mode rung, and an incomplete index table.

Treat the whole instruction set as one interconnected prompt: canonical numbers (budgets, caps) and schemes (naming, rungs) must match across files. Run this pass after probe fixes, on top of structural validation.
