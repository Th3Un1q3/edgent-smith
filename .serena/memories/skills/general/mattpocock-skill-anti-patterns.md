# mattpocock/skills: The 9 Anti-Patterns

Nine failure modes the library warns against (source: mattpocock/skills research, skill-quality campaign):

1. Vague generic advice — rules too abstract to act on.
2. Walls of text / context bloat — SKILL.md past the token budget readers actually pay.
3. Theory-dumping — explaining why instead of prescribing what to do.
4. Over-engineering — solving problems the skill never meets.
5. Negation-only steering — prohibition makes the forbidden behavior MORE available; prompt the positive behavior instead.
6. Process takeover — the skill's process replaces the user's own judgment and goal.
7. Inventing behavior / faking knowledge — never trust parametric memory; skills must not fabricate.
8. Making the human do the agent's job — shifting work the skill should do onto the reader.
9. Duplication / multiple sources of truth — reference by path, never copy.

Each anti-pattern maps to a positive reframe in building-modular-skills v3.5.0 (mem:skills/general/building-modular-skills-version-deltas).
