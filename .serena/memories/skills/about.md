# Skills Domain

This domain covers the context-gathering skill system — the reusable skill definitions, recipes, workflows, and memory conventions that govern how agents research, explore, and persist project knowledge.

## Scope
- Context-gathering skill structure (SKILL.md, workflows, recipes)
- Serena memory system conventions and patterns
- Recipe authoring standards and templates
- Memory write/read/edit/rename/delete patterns
- Cross-referencing with `mem:` links
