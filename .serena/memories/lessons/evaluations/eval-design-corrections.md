L0: "Eval design corrections: scenario prompts, no how-to, standalone fixture namespace, rug-swe agent, local model, one case end-to-end first."

- Scenario-only prompts: give the skill plus the action, no how-to steps.
- Target scenarios: single find, batch to structured, multi-memory report, reference updates, conflict, stale cleanup.
- Standalone eval namespace with fixtures.
- Use rug-swe for scenarios.
- Local model by default, fallback for rate limits.
- Token-conscious prompts and outputs.
- One case end-to-end before starting the next.
- Fix every chain breakage.
