# LinkedIn Research: Title-Verify Every Search Result Before Storing

LinkedIn search surfaces the WRONG entity frequently: regional offices and subsidiaries dominate
results. Verified wrong-entity hits: USU s.r.o. (subsidiary of USU Software AG) and INIT MENA
(regional arm of init SE).

Title-verify every search result / company page against the target entity name BEFORE storing
data. Unverifiable or redirected entities: record no-data with evidence instead of guessing
(see mem:browser-automation/linkedin/unclaimed-company-page-no-chart).
