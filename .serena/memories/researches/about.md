## Agent Workflow

- mem:researches/worktree-coding-workflow — PROPOSAL: a coding workflow that gives each task its own git worktree, moves the session into it, reloads skills at every stage boundary, validates with non-author sessions plus repo gates, then merges back only behind user authorization.
- mem:researches/parent-child-subagent-protocol — PROPOSAL: a parent/child token protocol (OUT=, IN=, HANDOFF=, GATE=) measured to save only ~2% of prompt characters; the larger lever is a brief written once into a memory and referenced by later children.
- mem:researches/prompt-compaction-tokens — PROPOSAL: Prompt scaffolding repeats each dispatch; #-tokens replace the repeats and stored briefs replace repeated content, taking prompts 28-33% lower after an 11.1% prose-only ceiling.
- mem:researches/write-once-read-many-context — PROPOSAL: write a dispatch brief once into a memory, then send later children its reference plus their delta; context reuse, not token compression, is the lever.
- mem:researches/labelled-subagent-sessions — PROPOSAL: a label is a session-scoped alias bound lazily on first subtask_run use from label to child session id; later calls in that session resolve it and continue the child. It names what the child does, not a persona.
