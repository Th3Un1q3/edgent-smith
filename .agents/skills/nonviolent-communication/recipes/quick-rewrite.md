# Recipe: 60-Second 4-Sentence Quick Rewrite

Produce a Giraffe message in under 60 seconds when time is short.

When to load: you need a fast rewrite without running the full 7-step workflow; pair with the rubric for a quick self-check.

## Template

"When I [observation], I feel [feeling] because I need [need]. Would you be willing to [request]?"

 - [observation] — camera-test fact: exact words/time/place. Passes "what would a video show?"
 - [feeling] — body feeling from real list (angry, scared, disappointed, hurt, anxious, frustrated, lonely). No faux-feeling.
 - [need] — universal noun, no "you", no strategy. Example: serenity, order, safety, respect, understanding, connection.
 - [request] — positive, concrete, present, doable, choice-honoring: "Would you be willing to…?"

## 60-Second Steps

1. Spot Jackal — underline evaluation, faux-feeling, "I need you to", or "don't". Done when: 1–2 traps named.
2. Fill observation — quote words or filmable action + when. Done when: sentence has time/place/quote.
3. Fill feeling + need — pick one real feeling + one universal need (no "you"). Done when: "I feel [real] because I need [universal]".
4. Fill request — name one positive doable action now/next + choice phrase. Done when: "Would you be willing to…?" present.
5. Speak the 4 sentences and score quickly (≥10/12 no zero via [references/rewrite-rubric.md](../references/rewrite-rubric.md)). Done when: no zero and total eyeballs to ≥10.

## Examples

Sink (video): "When I see dishes in the sink this morning, I feel disappointed because I need order. Would you be willing to rinse your dishes after dinner tonight?"

Big mouth (video): "When you said 'I'll tell them' at lunch today, I feel hurt because I need privacy. Would you be willing to check with me first?"

Windows (video): "When I see the ball near the windows, I feel worried because I need safety. Would you be willing to play in the backyard?"

## Checks

- Observation has a quote or filmable action — not "you are…".
- Feeling not in faux list (misunderstood, manipulated, judged, rejected, abandoned).
- Need contains no "you" and no location/action.
- Request is positive ("do X" not "don't Y"), concrete, now/next, and allows "no".
