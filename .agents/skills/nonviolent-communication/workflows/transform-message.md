# Workflow: Transform Any Message to NVC (Giraffe)

Rewrite a Jackal message into Rosenberg's 4-component Giraffe: Observation → Feeling → Need → Request.

When to load: user says "make this nonviolent", "rewrite with NVC", "turn any message to a non violent one", or provides a Jackal message to convert.

## Prerequisites

- Check `cache/youtube-videos/nvc/l7TONauJGfc.txt` (49,980 chars, 2015 SF Workshop) exists — read 2 KB excerpt to ground examples.
- Load [references/nvc-framework.md](../references/nvc-framework.md) for component definitions, [references/violent-patterns.md](../references/violent-patterns.md) for traps, [references/rewrite-rubric.md](../references/rewrite-rubric.md) for scoring.
- Input: one raw message to transform.

## Steps

1. **Cache and ground** — confirm video grounding is present. Done when: you cite the cache path and one video anchor (Jackal vs Giraffe, big heart, natural giving).
   - Example: cache `cache/youtube-videos/nvc/l7TONauJGfc.txt` holds 3h workshop; philosophy is connect to make natural giving possible.

2. **Detect Jackal** — scan the message for the 4 violence traps: evaluation, faux-feeling, need-as-strategy, demand. Done when: you list 1–3 flagged phrases with labels.
   - Example: "You have a big mouth!" → evaluation (labels person, not observable). "You yell at me" → evaluation ("yells" uncheckable); video corrects to "raised voice".
   - Probe: Ask "What words would a camera record?" If you cannot quote or film it, flag it.

3. **Extract observation without evaluation** — rewrite to camera-test facts: who, what, when, where, exact words. Done when: observation contains no adjective that judges character and passes "quote exact words".
   - Example: "You have a big mouth" → "When you said 'I told everyone you are...' yesterday at lunch".
   - Example: Lincoln High WHO YELLS — not "yells" but "when I hear a raised voice in the hallway at Lincoln High".

4. **Name the feeling without faux-feeling** — choose a body-based feeling from the real list. Done when: feeling appears in the real-feeling vocabulary and contains no "that I am / you made me / like I was".
   - Example: Replace "I feel misunderstood/manipulated/judged/rejected/abandoned" (faux) with "I feel angry / scared / disappointed / hurt / anxious / frustrated / lonely".
   - Walkthrough: "You have a big mouth → I feel hurt" not "I feel betrayed" without owning the judgment inside "betrayed".

5. **Uncover the universal need** — translate feeling into a need with no "you", no strategy, no location. Done when: need is universal (serenity, order, respect, understanding, safety, connection) and free of "that you…".
   - Example: Sink dishes → need is not "clean sink" (strategy) but "serenity and order when I enter the kitchen". Video: brother leaves dishes; need order/serenity.
   - Probe: Ask "Would everyone value this need if they felt the feeling?" If it names a person, it's a strategy.

6. **Craft a positive, concrete, present request with choice** — state what you want done, not what you want stopped; add "would you be willing to…?" Done when: request names a doable present action, no "don't", and honors refusal.
   - Example: "Don't break windows" fails — 38 windows story: tell a child "don't break windows" gives no actionable alternative; Giraffe says "Would you be willing to play ball in the backyard where the windows are safer?"
   - Example: 11-year "listen" fight: "I want you to listen to me" → "Would you be willing to tell me what you heard me say, so I know we connected?"
   - Criteria: positive (do vs don't), concrete (observable), present (now/next), doable (within power), choice (accepts no).

7. **Assemble and verify** — stitch the 4 sentences and score against the rubric. Done when: rubric total ≥10/12 with no zero; rewrite back with template.
   - Template: "When I [observation], I feel [feeling] because I need [need]. Would you be willing to [request]?"
   - Full walkthrough: Input "You have a big mouth! You always embarrass me." → "When I hear you share my story before I share it myself [observation], I feel hurt and anxious [feeling] because I need trust and respect for my privacy [need]. Would you be willing to check with me before sharing that story next time? [request]"
   - Gate: Score with [references/rewrite-rubric.md](../references/rewrite-rubric.md). No component scores 0. Total must reach 10. If not, revise the failing component and re-score.

## Gate

No delivery without rubric ≥10/12 and zero-free components. Re-run steps 3–6 for any component scoring 0–1.

## Acceptance Criteria

- Output contains exactly 4 labeled parts: Observation, Feeling, Need, Request.
- Observation quotes or films; no evaluative adjectives.
- Feeling uses real-feeling vocabulary only.
- Need contains no "you" and no strategy.
- Request is positive, concrete, present, and ends with choice language.
- Rubric score attached; pass is ≥10/12 no zero.

## Clarification Triggers

Ask before proceeding if:
- Message is ambiguous who did what — request the observable facts.
- Feeling could be faux — ask "what sensation in your body?"
- Request sounds like demand — add choice phrasing and test.
